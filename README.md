## 2. Постановка задачи

Проект рассчитывает характеристики студентов по дисциплинам на основе данных из файла. Базовый проект:

- читает список студентов и их оценки из текстового файла;
- рассчитывает средний рейтинг каждого студента;
- покрыт модульными тестами (pytest);
- проверяется линтером (pycodestyle);
- автоматически тестируется через GitHub Actions при push в main.

### Индивидуальное задание (вариант 1)

| Параметр | Значение |
|---|---|
| Формат входного файла | YAML |
| Расчётная процедура | Подсчёт количества студентов-отличников (все баллы >= 90) |

## 6. Архитектура

Проект построен по принципу разделения ответственности:

- Чтение — реализовано через абстрактный класс DataReader и его наследников TextDataReader / YamlDataReader. Это позволяет добавлять новые форматы без изменения остального кода (принцип открытости/закрытости).
- Расчёт — отдельные классы CalcRating (средний рейтинг) и ExcellentStudentsCalculator (количество отличников).
- Оркестрация — main.py выбирает нужный ридер по расширению файла и последовательно вызывает расчёты.

Подробная UML-диаграмма классов: diagrams/class_diagram.drawio.

## 9. Непрерывная интеграция (CI)

CI настроена через GitHub Actions в файле .github/workflows/github-actions-testing.yml.

Workflow запускается на:

- push в ветку main;
- pull request в main.

Шаги workflow:

1. Проверка репозитория (actions/checkout).
2. Установка Python 3.10 (actions/setup-python).
3. Установка зависимостей из requirements.txt.
4. Проверка стиля: pycodestyle src test.
5. Запуск тестов: pytest.

При успешном прохождении рядом с коммитом отображается зелёная галочка. При падении тестов — красный крестик.

### 9.1. Демонстрация срабатывания CI

В соответствии с п. 33 методических указаний была выполнена проверка:

1. В ExcellentStudentsCalculator.py условие s >= EXCELLENT_THRESHOLD было намеренно заменено на s > EXCELLENT_THRESHOLD.
2. Изменения закоммичены и запушены — CI упал (красный крестик), в логе видно 2 упавших теста.
3. Ошибка откатана, повторный push — CI прошёл (зелёная галочка).

Это подтверждает, что CI реально реагирует на изменения в коде.

- чтение пустого файла.

### 11.4. Класс ExcellentStudentsCalculator

Класс принимает на вход словарь студентов и возвращает количество студентов, у которых все баллы >= 90.

Покрыт тестами (test_ExcellentStudentsCalculator.py):

- два отличника;
- пустой словарь;
- все отличники;
- никто не отличник;
- граничный случай (ровно 90 — отличник, 89 — нет).
